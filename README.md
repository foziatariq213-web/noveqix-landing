# Noveqix — Landing Page

A clean, modern, responsive marketing landing page for **Noveqix**, an AI-driven universal QA automation platform. Built as a front-end UI concept in light mode, following the Noveqix brand (indigo → violet).

## Tech Stack

- **Next.js** (App Router)
- **Tailwind CSS** for styling
- **Framer Motion** for entrance & scroll animations
- **lucide-react** for icons

## Sections

- Sticky navbar with responsive mobile layout
- Hero with a code-built product dashboard mockup (animated count-up stats)
- "Integrates with your stack" strip
- Features grid (core capabilities, extended capabilities, key benefits)
- Footer with link columns and socials

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Notes

This is a static UI project — buttons, forms and navigation are non-functional by design, built to showcase layout, responsiveness and design quality.
